## Findings fed back into the work

1. Claude workers start in the user's default permission mode, and a fresh folder triggers Claude's folder-trust dialog. Both block an unattended run, and the orchestrator must not answer them (H8). → Added `init-run --agent-arg ARG` (passed after `--` to `herdr agent start`) so the user can choose the workers' mode up front (e.g. `--permission-mode auto`). Documented in SKILL.md / agents-and-safety.md: worktrees and new folders need the user to answer the trust dialog once.
2. `herdr agent read` / `pane read` print plain text; herdr's not-found code for panes is `pane_not_found` (used by init-run and teardown).
